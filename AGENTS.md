# Public repository guidance

This repository is documentation-only. Do not add private source, generated definitions, textures, models, build tooling, or unpublished release assets. Keep README and CHANGELOG aligned with the current public Workshop release.
## Public documentation maintenance

For TROA Tiered Tech 5.0, keep public docs limited to release-supported behavior. Treat source-closed or roadmap-only behavior as such, never expose secrets or private implementation details, and update the README, changelog, user guide, and this repository's context/log when documentation changes.
