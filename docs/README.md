# Tiered Tech documentation

Tiered Tech is installed by subscribing to the [official Space Engineers Workshop item](https://steamcommunity.com/sharedfiles/filedetails/?id=3804068289). This GitHub repository contains documentation, not the mod package.

- Start with the [README](../README.md) for installation, tier selection in the build menu, current behavior, and update notes.
- Use the [tier reference](TIERS.md) to compare tiers and unlock progression.
- Use [upgrade module and generator scaling](UPGRADE_MODULE_SCALING.md) for per-tier values and examples.
- Check [compatibility](COMPATIBILITY.md) and [changelog](../CHANGELOG.md) before updating.
- Since version 5.0.19, standalone Tiered LCD/text-panel blocks are removed; use vanilla LCDs instead.

Subscribe through Steam Workshop to install/update. After updating, allow the server to finish its normal definition loading and check logs for errors before players test the new blocks.
