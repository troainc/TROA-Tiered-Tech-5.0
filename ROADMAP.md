# Roadmap

## Development

- Complete functional and armor coverage generation.
- Complete Asgardian and Odin component progression.
- Populate all TROA Tiered Tech menu categories.
- Produce tier badges, feature cards, and progression charts.

## Testing

- Validate every menu category and search label in game.
- Place representative blocks from every tier, family, grid size, and armor class.
- Verify block performance, operating cost, recipes, and protection values.
- Test eligible DLC variants with the correct ownership indicators.
- Load legacy worlds containing 2x, 4x, 8x, and 16x blocks.
- Complete multiplayer and dedicated-server testing.
- Clear all new Space Engineers definition and asset log errors.

## Release

A public build, Workshop item, or downloadable package will be considered only after testing is complete and the project owner explicitly authorizes a release.
